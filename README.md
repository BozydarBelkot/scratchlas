# Scratchlas

Create an app with the following features:

Interactive Scratch Map System:

Toggle between a flat 2D map projection and an interactive 3D globe.

Granular tracking: Mark locations at country, state/province, city, and specific landmark/POI levels.

Location status tags: Categorize places as Visited, Want to Visit (Wish List), or Lived.

Visual feedback: A smooth "scratch-off" or color-fill animation when marking a new place as visited.

Travel Journal & Visual Timeline:

Group marked locations into chronological, trip-by-trip logs.

Upload geotagged photos and videos directly tied to specific map locations.

Passport Stats & Sharing:

Personal analytics dashboard showing percentage of world/continents visited, total country counts, and milestone badges.

Shareable map images, live web view links.

Offline Traveler Reference Data:

Native, local database containing essential information for each country (emergency numbers, driving side, plug outlet types, tap water safety, and currency details).

 Design Aesthetic:

Minimalist UI with high-contrast light and dark modes, customizable map color themes, and clean card-based navigation.
